GearPreview

Adds a scryTome Gear Preview button to the character window. It opens a window with a link to the scryTome Gear Preview (https://scrytome.org/ror-gear-preview/) that shows your worn items, dyes and appearance overrides.

Install: put the GearPreview folder in the game's Interface\AddOns folder and start the game.

Use: open the character window and press the scryTome Gear Preview icon in its title bar, or type /gp. Press Ctrl+A, Ctrl+C in the window and paste the link into a browser.

Source and issues: https://github.com/jmaartenson/GearPreview
